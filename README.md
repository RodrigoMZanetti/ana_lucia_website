# Ana-Lucia-Engenharia

Ana Lúcia Engenharia is a front-end website for a professional engineering company, featuring interactive elements, DOM manipulation, and structured JavaScript logic.

## Live Demo

## Tech Stack

- **Frontend:** JavaScript, HTML5, CSS3

## Features

- Browse engineering services and portfolio
- Navigate between pages (home, services, store)
- Interactive form with real-time validation
- Responsive layout for mobile and desktop

## Running Locally

- Clone the repository and open `index.html` in your browser.
- Optional: use VS Code Live Server for a better local experience.
